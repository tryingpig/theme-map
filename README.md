# 테마 맵 (theme-map)

테마별 구성종목의 **종가 기준** 수익률과 고점대비 위치를 한 표에서 보는 정적 대시보드.
원자력을 시작으로 테마를 계속 늘려 간다.

🔗 https://tryingpig.github.io/theme-map/  (`?theme=원자력`, 마지막 본 테마 기억)

## 계층 — 대테마 > 역할 > 종목

테마는 종목을 묶는 태그가 아니라 **집계 단위**다. 화면 맨 앞에 테마 자체의 수익률이 오고,
그 아래에 역할 그룹이 붙는다. "오늘 원자력이 올랐다"가 아니라 "오늘은 정비주가 갔고 EPC는 안 갔다"를 본다.

| 층 | 값의 정체 |
|---|---|
| 대테마 | 구성종목 **동일가중 지수** (일간수익률 평균을 누적, 최근 5년 구간) |
| 역할 | 구성종목 지표의 **단순 평균** |
| 종목 | 실제 종가에서 계산한 값 |

동일가중 지수를 가격 평균이 아니라 일간수익률 누적으로 만드는 이유는, 상장일이 제각각인
테마(우진엔텍 2024년 상장 등)에서 신규 편입일에 지수가 튀지 않게 하기 위해서다.

## 계산 규칙

사용자가 준 증권사 화면을 역산해 그대로 맞췄다. 2026-08-26 종가로 16종목 현재가와
7종목 지표가 소수 둘째 자리까지 일치하는 것을 확인했다.

| 컬럼 | 정의 |
|---|---|
| %1일 · %5일 | 거래일 1일 / 5일 전 종가 대비 |
| %1개월 · %1년 | **캘린더** 1개월 / 1년 전 날짜 이하 마지막 거래일 대비 |
| 52주 고점대비 | 최근 1년 **장중 최고가(High)** 대비 현재 종가 |
| 사상 고점대비 | 전 기간 장중 최고가 대비 현재 종가 |

- 거래일 21/252일로는 재현되지 않는다(두산에너빌리티 1년: 거래일 기준 23.6~49.5로 흩어지는데 정답 35.55는 캘린더에서만 나온다).
- 가격은 조정 없는 `Close`. Yahoo의 `Close`는 액면분할이 반영되고 배당은 미반영이라 국내 HTS와 같다.
  `Adj Close`를 쓰면 배당이 섞여 어긋난다(한전KPS 1년 -4.70 → -1.41).
- `core.PERIOD_MODE = "trading"`으로 두면 거래일(21/252) 기준으로도 계산된다.

## 구조

| 파일 | 역할 |
|---|---|
| `scripts/core.py` | 테마 무관 공용 — 수집·지표·동일가중 지수 |
| `scripts/build.py` | 드라이버 — `python scripts/build.py [테마…]`, 테마별 격리 실행 |
| `scripts/sync_from_notion.py` | 노션 'Theme Map DB' → `data/universe.json` |
| `data/universe.json` | 유니버스 (노션 동기화 산출물 겸 폴백) |
| `data/index.json` | 테마 목록 + 테마별 지수 지표 (탭 렌더용) |
| `data/themes/{테마}.json` | 테마 하나의 계층·지표 전부 |
| `index.html` / `assets/` | 단일 페이지 + 테마 탭 + 히트맵 표 |
| `.github/workflows/update.yml` | 평일 18:30 KST 갱신 |

## 테마를 늘리는 법 (코드 수정 없음)

1. 노션 **Theme Map DB**의 `대테마` multi-select에 옵션을 추가한다.
2. 종목 행을 만들고 `대테마`를 태깅한다. `역할`은 그 테마에 맞는 옵션을 새로 넣으면 된다.
3. 다음 갱신 때 웹 상단에 탭이 자동으로 생긴다.

한 종목이 여러 테마에 걸치면 태그를 두 개 달면 된다(행은 하나로 유지). 표시 순서는
`정렬순서` 숫자 하나로 정해진다 — 역할 그룹 순서도 그룹 내 최솟값으로 따라온다.

## 로컬 실행

```bash
pip install -r requirements.txt
# 유니버스를 노션에서 새로 받으려면:
#   NOTION_TOKEN=... python scripts/sync_from_notion.py
python scripts/build.py            # data/index.json · data/themes/*.json 생성
python -m http.server 8000         # http://localhost:8000/
```

> 정보 제공용이며 투자 권유가 아닙니다.
