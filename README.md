# 테마 맵 (theme-map)

테마별 구성종목의 **종가 기준** 수익률과 고점대비 위치를 한 표에서 보는 정적 대시보드.
원자력을 시작으로 테마를 계속 늘려 간다.

🔗 https://tryingpig.github.io/theme-map/ — 메인은 **코스피·코스닥 대비 테마 수익률**,
테마를 누르면 `theme.html?theme=원자력` 구성종목 화면으로 들어간다.

## 계층 — 대테마 > 역할 > 종목

테마는 종목을 묶는 태그가 아니라 **집계 단위**다. 화면 맨 앞에 테마 자체의 수익률이 오고,
그 아래에 역할 그룹이 붙는다. "오늘 원자력이 올랐다"가 아니라 "오늘은 정비주가 갔고 EPC는 안 갔다"를 본다.

| 층 | 값의 정체 |
|---|---|
| 대테마 | 구성종목 **동일가중 지수** (일간수익률 평균을 누적, 최근 5년 구간) |
| 역할 | 구성종목 지표의 **단순 평균** |
| 종목 | 실제 종가에서 계산한 값 |

동일가중 지수를 가격 평균이 아니라 일간수익률 누적으로 만드는 이유는, 상장일이 제각각인
테마(우진엔텍 2024년 상장 등)에서 신규 편입일에 지수가 튀지 않게 하기 위해서다.

## 시장 비교 (메인 화면)

"내가 보는 테마가 시장을 이기고 있나"가 이 화면의 질문이다.

- 코스피(`^KS11`)·코스닥(`^KQ11`)과 테마 지수를 **같은 날짜축(코스피 거래일)** 위에 올려 저장한다(`data/series.json`).
- 시계열은 **적립식**이다 — 매 실행마다 다시 계산하지 않고 새 거래일만 이어 붙인다(아래 참고).
- 차트의 y축은 지수 레벨이 아니라 **기간 시작 대비 %**다. 레벨이 다른 계열(테마 1,282 vs 코스피 6,912)을
  한 축에서 비교하려면 이 방법뿐이다 — 축을 둘로 나누지 않는다.
- `절대 수익률` / `코스피 대비` 토글. 후자는 코스피가 0% 평평한 선이 되고, 위로 올라간 테마가 그 구간에서 시장을 이긴 테마다.
  초과수익은 뺄셈(%p)이 아니라 비율의 비율로 계산한다(구간이 길수록 복리 차이가 커진다).
- 기간은 **1주·2주·1개월·3개월·6개월·1년(최대)**. 시작점은 표의 `%1개월`·`%1년`과 **같은 캘린더 규칙**
  (1주 = 캘린더 7일 전 이하 마지막 거래일)이라 차트와 표가 서로 어긋나지 않는다 — 1주 수익률은 `%5일`과 같은 값이 된다.
- 계열 색은 테마 순서로 **고정**된다(순위나 표시 개수에 따라 바뀌지 않는다). 8색 팔레트는 색각 이상·명암 검증을 통과한 값이다.

### 시장을 이기기 시작한 시점

상대강도 **RS = 테마지수 ÷ 코스피**가 자기 **20일 이동평균**을 위로 넘은 날이 '우위 전환'이다.
비율이라 기간을 어떻게 잘라 봐도 전환일은 그대로다. 판정은 **돌파 즉시**(확인 기간 없음) —
반응이 가장 빠른 대신 하루 스쳤다 되돌아가는 신호도 잡힌다.

- 판정은 `scripts/build.py`의 `rs_signal()`에서 **한 번만** 하고 `data/index.json`의 테마마다 `rs`로 실린다.
  화면(순위표 '우위 전환' 칸·차트의 ◉ 마커)과 텔레그램 알림이 같은 값을 본다.
- 상세 화면에서 `코스피 대비`로 바꾸면 RS의 20일선이 점선으로 같이 그려진다.
- 알림은 별도 에이전트 `C:/ClaudeCode/theme-map-alert`가 배포된 `index.json`을 읽어 보낸다
  (공개 레포라 토큰을 넣지 않는다 — EpicAI-Monitor의 봇을 빌린다).

### 지수는 적립한다 (재계산하지 않는다)

매 실행마다 전 구간을 다시 계산하면, 오늘 종목 하나를 빼는 순간 3개월 전 수익률까지 같이 바뀐다.
그러면 "그때 이 테마가 얼마였나"라는 기록이 남지 않는다. 그래서:

| 상황 | 하는 일 |
|---|---|
| 이미 저장된 날 | 저장된 값 그대로 (**절대 다시 계산하지 않는다**) |
| 새 거래일 | 마지막 지수 × (1 + 그날 구성종목 평균 등락률) |
| 새 테마·최초 실행 | `core.BACKFILL_DAYS`(300거래일)만큼 한 번 소급해 깔고 100에서 시작 |

구성 변경은 **변경한 날 이후에만** 영향을 준다. 지수 레벨이 이어지므로 편입·제외로 선이 튀지 않는다.
값은 소수 넷째 자리까지 저장한다 — 저장값에서 다시 곱해 이어 가므로 두 자리로 자르면 반올림 오차가 쌓인다.
적립분을 버리고 현재 구성으로 다시 깔아야 하면 `python scripts/build.py --rebuild-series`(비상용).

최대 기간이 1년인 것도 같은 이유다. 그보다 긴 구간은 소급 계산으로만 만들 수 있는데, 그건 기록이 아니다.
적립이 쌓이면 그때 기간을 늘리면 된다.

## 계산 규칙

사용자가 준 증권사 화면을 역산해 그대로 맞췄다. 2026-08-26 종가로 16종목 현재가와
7종목 지표가 소수 둘째 자리까지 일치하는 것을 확인했다.

| 컬럼 | 정의 |
|---|---|
| %1일 · %5일 | 거래일 1일 / 5일 전 종가 대비 |
| %1개월 · %1년 | **캘린더** 1개월 / 1년 전 날짜 이하 마지막 거래일 대비 |
| 52주 고점대비 | 최근 1년 **장중 최고가(High)** 대비 현재 종가 |
| 사상 고점대비 | 전 기간 장중 최고가 대비 현재 종가 |

- 거래일 21/252일로는 재현되지 않는다(두산에너빌리티 1년: 거래일 기준 23.6~49.5로 흩어지는데 정답 35.55는 캘린더에서만 나온다).
- 가격은 조정 없는 `Close`. Yahoo의 `Close`는 액면분할이 반영되고 배당은 미반영이라 국내 HTS와 같다.
  `Adj Close`를 쓰면 배당이 섞여 어긋난다(한전KPS 1년 -4.70 → -1.41).
- `core.PERIOD_MODE = "trading"`으로 두면 거래일(21/252) 기준으로도 계산된다.

## 구조

| 파일 | 역할 |
|---|---|
| `scripts/core.py` | 테마 무관 공용 — 수집·지표·동일가중 지수 |
| `scripts/build.py` | 드라이버 — `python scripts/build.py [테마…]`, 테마별 격리 실행 |
| `scripts/sync_from_notion.py` | 노션 'Theme Map DB' → `data/universe.json` |
| `data/universe.json` | 유니버스 (노션 동기화 산출물 겸 폴백) |
| `data/index.json` | 테마 목록 + 테마별 지수 지표 (탭 렌더용) |
| `data/themes/{테마}.json` | 테마 하나의 계층·지표 + 그 테마 지수의 일별 시계열 |
| `data/series.json` | 코스피·코스닥·전체 테마의 **적립된** 일별 시계열 (메인 차트용) |
| `index.html` / `assets/main.js` | 메인 — 시장 대비 차트 + 순위표 |
| `theme.html` / `assets/app.js` | 상세 — 테마 탭 + 히트맵 표 + 그 테마의 시장 대비 차트 |
| `assets/chart.js` | 공용 라인 차트 (SVG 직접 그림, 외부 라이브러리 없음) |
| `.github/workflows/update.yml` | 평일 18:30 KST 갱신 |

## 테마를 늘리는 법 (코드 수정 없음)

1. 노션 **Theme Map DB**의 `대테마` multi-select에 옵션을 추가한다.
2. 종목 행을 만들고 `대테마`를 태깅한다. `역할`은 그 테마에 맞는 옵션을 새로 넣으면 된다.
3. 다음 갱신 때 웹 상단에 탭이 자동으로 생긴다.

한 종목이 여러 테마에 걸치면 태그를 두 개 달면 된다(행은 하나로 유지). 표시 순서는
`정렬순서` 숫자 하나로 정해진다 — 역할 그룹 순서도 그룹 내 최솟값으로 따라온다.

## 로컬 실행

```bash
pip install -r requirements.txt
# 유니버스를 노션에서 새로 받으려면:
#   NOTION_TOKEN=... python scripts/sync_from_notion.py
python scripts/build.py            # data/index.json · data/series.json · data/themes/*.json 생성
python -m http.server 8000         # http://localhost:8000/
```

> 정보 제공용이며 투자 권유가 아닙니다.
